## 实际结果

- 丙辰年十二月（月序 5653）的 `dayCount` 从 29 修正为 28：同步 28 条逐日源记录、1 条月份导入记录以及基础 SQLite。上游原始文件保持不变。导入器优先使用相邻月初跨度，未提供下一月初的年末项继续使用上游完整月长。
- 数据契约接受 `1...30` 的实际月长，大小月格式化对 `1..<30` 显示“小”、30 显示“大”；包括 23、28、29 天。数据覆盖首尾部分月份不按现存日记录数缩短。
- `LunarMonthDateIndex` 从完整月长构建累计边界，以二分查找定位月序与月内日号。默认锚点为月序 0 的初一 JDN 1640700，支持显式锚点；拒绝月序缺口、乱序、非法月长、溢出和范围外目标。
- Resolver 在没有真实日记录时使用数据库月表累计定位；有真实日记录时继续精确选择该日。首页使用 `.today` 落点，年月及闰月信息从记录取得。运行时代码已无 `Calendar(identifier: .chinese)` 调用。
- 显式指定年份而“今天”不可定位时，仍可进入该年首个真实月份；首页的 `.today` 不以年首月替代无法定位的今天。
