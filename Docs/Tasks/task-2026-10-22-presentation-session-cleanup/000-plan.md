## 目标与范围

删除 `NavigationHostConfiguration.presentationDidDismiss()` 及其调用。保留 Core 宿主自动处理真实关闭完成和延迟导航的职责，接好年份选择、DEBUG 下载演示、分栏缓存和提示文案的释放。

## 方案

配置只构建页面、提示并处理 alert 动作，不增加替代的全局业务回调。Core 提供仍需保留业务数据的呈现路由投影，包含活动、排队及正在关闭的模态；关闭中的节点保留至实际完成，随后从投影移除。此投影只表达运行时身份，不保存业务数据或回调。

App 稳定的根宿主观察该投影和 alert 路由。coordinator 根据具体 destination 中的 sessionID 释放已结束会话；分栏缓存按原栈对象是否仍由导航树保留来清理。正常关闭期间继续保留数据，store identity 失效仍立即撤销旧年份会话。
