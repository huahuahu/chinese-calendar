# 当前界面截图基准：方案

- 状态：可执行
- 更新日期：2026-10-24
- 需求：加入截图测试，先固定当前界面。

## 目标与范围

复用 `PreviewSampleData` 的内存数据库和固定日期，为当前日历、历史、设置页面及主要边界状态生成可比较的 PNG 基准。保留当前生产界面和文案，截图测试关注固定视口内的渲染结果。

## 方案与决策

- 使用测试专用的 Point-Free SnapshotTesting 1.19.7，固定依赖版本。通过 `project.yml` 创建独立的 App 承载截图测试 target；不向生产 Swift Package 增加依赖。
- 在 `Tests/Snapshots` 保存测试及基准图。每个场景创建独立内存容器和页面状态，复用现有示例数据工厂，并注入固定日期、简体中文、上海时区、明确的浅色／深色、字号和视口尺寸。
- 首批覆盖日历默认、纪元边界、后九月、空态、年份选择器、历史主要页面、设置，另覆盖宽屏、深色和辅助功能字号。最终矩阵由实际可渲染的页面入口确定并记入结果。
- 比较与录制使用独立 scheme；默认比较模式在缺失基准或图像变化时失败，不静默更新基准。
- 使用共享配置中的 Simulator（iOS 27.0）录制，固定基准运行环境并提供本地脚本与 CI 比较入口。平台或运行时变化须显式重新评估基准。
- 按 [通用规范](../../Conventions/Common.md)、[SwiftUI 规范](../../Conventions/SwiftUI.md)、[导航规范](../../Conventions/Navigation.md) 实现。构建测试遵循 [Xcode 工作流](../../agent-workflows.md#xcode-project-context)。

## 验收标准

| ID | 预期行为 | 验证方式 |
| --- | --- | --- |
| AC-01 | 可执行截图 suite 复用现有 sample data，生产 UI 行为不变 | 源码检查及 Simulator 测试 |
| AC-02 | PNG 基准覆盖首批主要页面与边界状态，图像有真实内容 | 录制、逐组视觉检查 |
| AC-03 | 比较模式稳定通过，不修改基准 | 完整比较运行及基准摘要检查 |
| AC-04 | 缺失／不匹配基准能够使测试失败且提供诊断 | 临时更改基准的负向验证后恢复 |
| AC-05 | 本地与 CI 有明确固定环境、录制和比较命令 | 脚本检查、配置检查、文档 |
| AC-06 | 格式、lint、现有 UI 测试通过 | 项目检查及测试 |

## 验证边界

截图测试固定当前视觉结果，不代替导航交互、系统弹窗、下载流程或真机验证。远程 CI 未实际执行时在结果中单列。
